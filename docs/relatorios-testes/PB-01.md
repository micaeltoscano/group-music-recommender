## Defeitos encontrados

### DEF-PB01-01 — Critério 1 não comprovável: frontend nativo não executável (Node ausente)
- Severidade: **Média** (bloqueio de ambiente; não é defeito de código)
- Caso relacionado: CT-PB01-06
- Passos: `cd frontend && npm install && npm run dev` → falha (`node`/`npm` não encontrados no host)
- Esperado: Vite em `http://localhost:5173` com três indicadores "ok"
- Observado: impossível iniciar — toolchain ausente
- Impacto: critério 1 do PB-01 permanece sem evidência; validação do PB fica **impedida**
- Recomendação: instalar Node.js ≥ 18 no host e reexecutar CT-PB01-06 com captura de tela.

### DEF-PB01-02 — Divergência de nomes de variáveis entre `.env` local e `.env.example`
- Severidade: **Baixa** (fora do escopo funcional do PB-01; higiene de configuração)
- Caso relacionado: CT-PB01-05
- Observado: o `.env` local usa chaves `CLIENT_ID`/`CLIENT_SECRET` (com espaço antes do `=`),
  enquanto `.env.example` e `config.py` esperam `SPOTIFY_CLIENT_ID`/`SPOTIFY_CLIENT_SECRET`.
- Impacto: nenhum no PB-01 (essas variáveis são de histórias futuras e opcionais); mas causará
  confusão no PB-02. Não expõe segredo versionado.
- Recomendação: alinhar os nomes no `.env` local aos do `.env.example` antes do PB-02.
