- Severidade: **Alta**
- Caso relacionado: CT-PB34-04
- Pré-condições: biblioteca persistida com zero faixas e snapshot Top médio válido.
- Passos: executar `test_qa_ct_pb34_04_biblioteca_vazia_com_tops_aciona_fallback`.
- Esperado: adaptador retorna ausência utilizável e geração segue pelo fallback PB-08.
- Observado: `LibraryGenerationData` com perfil/candidatas vazios; pipeline lança
  `InsufficientTracksError` antes de usar os Tops.
- Evidência: `backend/tests/test_pb34_library_generation_qa.py`.
- Módulo relacionado: `library_application_service.load_library_generation_data`.
- Impacto: usuário com biblioteca vazia não consegue demonstrar geração apesar de possuir Tops.
- Recomendação: tratar snapshot vazio ou perfil/pool sem candidatas como indisponível e retornar
  `None`, preservando o caminho Top existente.
- Status: **Revalidado** — commit `d9227cc`; linha ausente, `track_count=0`, perfil vazio e pool vazio
  retornam `None` ao pipeline e preservam o fallback Top.
