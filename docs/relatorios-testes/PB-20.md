## Critérios de aceitação (todos comprovados)

1. **Feedback por faixa** — `POST /playlist-runs/{id}/tracks/{track_id}/feedback` registra
   like/dislike/more_like_this/never_again.
2. **Feedback geral** — `POST /playlist-runs/{id}/feedback` persiste `representation_score` e
   `satisfaction_score` (0–5) e comentário opcional.
3. **Associação à execução/usuário corretos** — vínculo por `playlist_run_id` + `user_id`; faixa deve
   pertencer ao run e estar `matched`.
4. **Não-membro não registra** — autorização por membership da sala do run → 403; não autenticado → 401.
5. **Aviso de uso futuro** — API e UI declaram que o feedback é para evoluções futuras e não altera o
   ranking do MVP.
